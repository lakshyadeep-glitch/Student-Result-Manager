# Student Result Manager

A simple Python application to manage student records, calculate percentages, and store data using file handling.

## Features

* Add student records
* View all students
* Calculate percentage
* Save student data to a text file
* Load saved student data automatically

## Technologies Used

* Python
* Lists
* Dictionaries
* Functions
* File Handling

## Project Structure

```text
Student-Result-Manager/
│
├── main.py
├── student.txt
└── README.md
```

## How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder.
4. Run:

```bash
python main.py
```
